# Feature 6: Watchlist & Persistence

## Description
Enables users to manage a custom list of symbols and ensures their preferences are saved across sessions.

## Key Features
- **Sidebar Watchlist**: A dedicated sidebar to manage and monitor multiple symbols.
- **Real-time Updates**: Each watchlist item receives real-time price and 24h change updates via WebSockets.
- **Persistence**: Watchlist and chart resolution preferences are saved in `localStorage`.
- **Interactivity**: Clicking a watchlist item updates the main interactive chart.
